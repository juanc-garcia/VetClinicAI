# VetClinicAI

## Project Goal

This repository demonstrates how multiple GitHub Copilot custom agents collaborate to transform an initial business idea into a software product.

The repository simulates an Agile software development team composed of specialized AI agents.

## Business Idea

Develop a veterinary clinic management application.

The application should allow veterinary staff to:

- Manage appointments
- Register pets
- Register pet owners
- Track vaccinations
- Track deworming treatments
- Monitor weight history
- Record medical history
- Send preventive care reminders
